# Bandit Level 3 → 4

## Goal

Find the password for Level 4.

## Commands 

### 1. List files 

```bash
ls -la
```

The `-a` option shows hidden files.

(`-a` ใช้แสดงไฟล์ซ่อนด้วย)

### 2. Enter the directory (เข้าไดเรกทอรี)

```bash
cd ~/inhere
```

The command opens the `inhere` directory in the current user's home directory.

(คำสั่งนี้เข้าโฟลเดอร์ `inhere` ภายใน Home directory ของผู้ใช้ปัจจุบัน)

### 3. Find the hidden file (ค้นหาไฟล์ซ่อน)

```bash
ls -la
```

Look for a filename that starts with a dot (`.`).

(สังเกตชื่อไฟล์ที่ขึ้นต้นด้วยจุด)

### 4. Read the file

Use `cat` with the actual hidden filename you found.

## What I Learned (สิ่งที่ได้เรียนรู้)

- `ls -a` shows hidden files.
- `ls -l` shows file details.
- `cd` changes the current directory.
- `cat` displays file contents.

## Result (ผลลัพธ์)

Found the password for Level 4.

Passwords are stored locally and are not included in this repository.
