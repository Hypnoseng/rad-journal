# Bandit Level 0 → 1

## Goal

Find the password for Level 1.

## Commands (คำสั่งที่ใช้)

### 1. List files (แสดงรายการไฟล์)

```bash
ls -l
```

The output showed a file named `readme`.

(ผลลัพธ์แสดงไฟล์ชื่อ `readme`)

### 2. Read a file (อ่านเนื้อหาไฟล์)

```bash
cat readme
```

The command displayed the file contents. The password was stored in this file.

(คำสั่งนี้แสดงเนื้อหาภายในไฟล์ ซึ่งมีรหัสผ่านอยู่)

## What I Learned (สิ่งที่ได้เรียนรู้)

- `ls` lists files and directories. (แสดงรายการไฟล์และไดเรกทอรี)
- `ls -l` shows file details. (แสดงรายละเอียดของไฟล์)
- `cat` displays file contents. (แสดงเนื้อหาไฟล์)
- SSH connects to a remote server. (ใช้เชื่อมต่อกับเซิร์ฟเวอร์ระยะไกล)

## Result (ผลลัพธ์)

Found the password for Level 1.

Passwords are stored locally and are not included in this repository.

(เก็บรหัสผ่านไว้ในเครื่องเท่านั้น และไม่อัปโหลดลง GitHub)
